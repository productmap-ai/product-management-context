## Tools

### Maze AI
- **Pricing:** Free / Professional $99/mo / Organization custom
- **Best PM use cases:** Unmoderated usability testing, concept validation, prototype testing, AI-assisted insight reports
- **Key artefacts it helps create:** Usability test report, concept validation results, task success metrics

### Hotjar AI
- **Pricing:** Basic free / Plus $39/mo / Business $99/mo
- **Best PM use cases:** Session replay, heatmaps, on-site surveys, user sentiment analysis
- **Key artefacts it helps create:** Heatmap report, funnel drop-off analysis, NPS dashboard

### Sprig
- **Pricing:** Free (limited) / Starter $175/mo
- **Best PM use cases:** In-product micro-surveys, AI-powered insight synthesis, contextual feedback collection
- **Key artefacts it helps create:** In-product NPS, feature satisfaction surveys, user sentiment trends

### Dovetail
- **Pricing:** Starter $29/mo / Team $99/mo
- **Best PM use cases:** Centralised research repository, AI-assisted tagging, insight sharing across teams
- **Key artefacts it helps create:** Research synthesis, tagged insight library, evidence-backed product decisions

### Typeform
- **Pricing:** Free / Basic $25/mo / Plus $50/mo
- **Best PM use cases:** Conversational survey design, lead qualification forms, user onboarding questionnaires
- **Key artefacts it helps create:** PMF survey, NPS survey, user research screener

### SurveyMonkey Genius (SurveyMonkey AI)
- **Pricing:** Team Advantage $25/user/mo / Team Premier $75/user/mo
- **Best PM use cases:** AI-assisted survey design, response analysis, benchmark comparisons
- **Key artefacts it helps create:** User satisfaction survey, PMF survey, feature prioritisation survey
