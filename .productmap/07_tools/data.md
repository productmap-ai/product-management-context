## Tools

### Julius AI
- **Pricing:** Basic $20/mo / Essential $49/mo
- **Best PM use cases:** Natural language data analysis, chart generation from CSV/Excel uploads, quick statistical summaries
- **Key artefacts it helps create:** Data visualisations, metric summaries, ad hoc analysis reports

### Rows.com
- **Pricing:** Free / Plus $59/mo / Business $199/mo
- **Best PM use cases:** Spreadsheet with live API integrations, AI-assisted formula writing, automated data pulls
- **Key artefacts it helps create:** Live dashboards, automated reports, financial models with live data

### Airtable AI
- **Pricing:** Free / Team $20/seat/mo / Business $45/seat/mo
- **Best PM use cases:** Structured database management with AI summarisation, roadmap tracking, content operations
- **Key artefacts it helps create:** Feature roadmap, content calendar, research repository

### Excel Copilot (Microsoft)
- **Pricing:** Included with Microsoft 365 Copilot ($30/user/mo add-on)
- **Best PM use cases:** Formula generation, data analysis, chart creation, model documentation via natural language
- **Key artefacts it helps create:** Financial models, revenue forecasts, metric dashboards

### Google Sheets + Gemini
- **Pricing:** Included with Google Workspace Business or Google One AI Premium
- **Best PM use cases:** Formula help, data summarisation, chart generation, collaborative modelling
- **Key artefacts it helps create:** Collaborative financial models, KPI trackers, experiment logs

### Equals
- **Pricing:** Starter $49/mo / Pro $99/mo
- **Best PM use cases:** Spreadsheet-native SaaS analytics, live database connections (Stripe, Postgres, etc.), version control for models
- **Key artefacts it helps create:** LTV/CAC models, revenue forecasts, subscription analytics
