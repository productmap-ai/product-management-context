## Tools

### Jira AI (Atlassian)
- **Pricing:** Free (up to 10 users) / Standard $8.15/user/mo / Premium $16/user/mo
- **Best PM use cases:** Enterprise backlog management, sprint planning, epic tracking, integration with Confluence and developer tools
- **Key artefacts it helps create:** Sprint plan, backlog, release notes, burndown charts

### Linear
- **Pricing:** Free / Standard $8/user/mo / Plus $14/user/mo
- **Best PM use cases:** Engineering-friendly issue tracking, cycle time analytics, fast keyboard-driven UX, async-first workflows
- **Key artefacts it helps create:** Sprint cycles, roadmap view, issue database

### ClickUp AI
- **Pricing:** Free / Unlimited $7/mo / Business $12/mo
- **Best PM use cases:** All-in-one PM tool, AI writing and summarisation, OKR tracking, automation
- **Key artefacts it helps create:** Project plans, OKRs, meeting notes, stakeholder docs

### Productboard
- **Pricing:** Starter $20/maker/mo / Pro $80/maker/mo
- **Best PM use cases:** Customer feedback management, roadmap prioritisation, feature voting, insights integration
- **Key artefacts it helps create:** Prioritised roadmap, feedback repository, feature scorecard

### Aha!
- **Pricing:** Roadmaps $59/user/mo
- **Best PM use cases:** Strategy-to-roadmap alignment, portfolio management, business goals tracking
- **Key artefacts it helps create:** Strategy roadmap, product scorecard, release plan

### Airfocus
- **Pricing:** Core $15/editor/mo / Advanced $59/editor/mo
- **Best PM use cases:** Prioritisation scoring, OKR-linked roadmaps, stakeholder portal, modular PM tool
- **Key artefacts it helps create:** Prioritised backlog, OKR roadmap, stakeholder-facing roadmap

### Monday.com AI
- **Pricing:** Free / Basic $9/seat/mo / Standard $12/seat/mo
- **Best PM use cases:** Cross-functional project tracking, AI-assisted automation, workflow templates
- **Key artefacts it helps create:** Project timelines, status dashboards, workflow automations
