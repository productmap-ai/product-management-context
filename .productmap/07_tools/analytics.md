## Tools

### Amplitude AI
- **Pricing:** Starter free / Plus $61/mo / Growth custom
- **Best PM use cases:** Behavioural analytics, retention analysis, funnel optimisation, A/B test analysis, AI-assisted insight surfacing
- **Key artefacts it helps create:** Cohort analysis, funnel report, retention report, A/B test report

### Mixpanel
- **Pricing:** Free (up to 20M events) / Growth $20/mo+
- **Best PM use cases:** Event-based product analytics, user journey analysis, real-time funnel tracking
- **Key artefacts it helps create:** Funnel analysis, user segmentation, event flow reports

### Google Analytics (GA4)
- **Pricing:** Free / GA4 360 enterprise pricing
- **Best PM use cases:** Web and app traffic analysis, acquisition channel performance, conversion tracking
- **Key artefacts it helps create:** Acquisition report, conversion funnel, audience analysis

### Tableau AI
- **Pricing:** Viewer $15/mo / Explorer $42/mo / Creator $70/mo
- **Best PM use cases:** Custom data visualisation, business intelligence dashboards, cross-source data analysis
- **Key artefacts it helps create:** Executive dashboards, KPI reports, trend analysis

### PostHog
- **Pricing:** Free (1M events/mo) / paid from $0.00045/event
- **Best PM use cases:** Open-source product analytics, session replay, feature flags, A/B testing
- **Key artefacts it helps create:** Funnel analysis, session replay reports, A/B test results

### Heap
- **Pricing:** Free (limited) / custom enterprise
- **Best PM use cases:** Retroactive event tracking (no pre-instrumentation), auto-capture of all user interactions
- **Key artefacts it helps create:** User journey analysis, feature adoption reports
