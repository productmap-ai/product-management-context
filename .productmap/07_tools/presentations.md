## Tools

### Gamma
- **Pricing:** Free / Plus $10/mo / Pro $20/mo
- **Best PM use cases:** AI-generated slide decks from prompts or documents, quick narrative presentations, internal briefings
- **Key artefacts it helps create:** Product brief, roadmap presentation, GTM deck, strategy overview

### Beautiful.ai
- **Pricing:** Pro $12/mo / Team $40/mo per user
- **Best PM use cases:** Professionally designed slides with smart layouts, data visualisations, consistent brand decks
- **Key artefacts it helps create:** Investor deck, growth model presentation, board update

### Pitch
- **Pricing:** Free / Pro $8/mo / Business $15/mo per user
- **Best PM use cases:** Collaborative deck creation, brand templates, async video recording on slides
- **Key artefacts it helps create:** Pitch deck, product demo slides, team presentations

### Slidebean
- **Pricing:** Content $29/mo / All Access $99/mo
- **Best PM use cases:** Startup pitch deck creation with AI-generated content and design
- **Key artefacts it helps create:** Investor pitch deck, product presentation

### Decktopus
- **Pricing:** Pro $9.99/mo / Business $36/mo
- **Best PM use cases:** AI-generated presentations from text prompts, interactive slide features
- **Key artefacts it helps create:** Quick presentations, product one-pagers

### Microsoft Copilot for PowerPoint
- **Pricing:** Included with Microsoft 365 Copilot ($30/user/mo add-on)
- **Best PM use cases:** AI-assisted slide creation within PowerPoint, Word-to-presentation conversion, speaker note generation
- **Key artefacts it helps create:** Board deck, stakeholder presentation, product review deck
