## Tools

### Figma AI
- **Pricing:** Starter free / Professional $15/editor/mo / Organization $45/editor/mo
- **Best PM use cases:** Collaborative wireframing, prototype creation, design review, AI-generated component suggestions
- **Key artefacts it helps create:** Wireframes, prototypes, design specs, component libraries

### Uizard
- **Pricing:** Free / Pro $12/mo / Business $39/mo
- **Best PM use cases:** Rapid wireframe creation from text prompts or screenshots, concept exploration
- **Key artefacts it helps create:** Wireframes, low-fidelity prototypes, user flows

### Visily
- **Pricing:** Free / Team $8/mo per user
- **Best PM use cases:** Sketch-to-wireframe conversion, AI-generated UI from text descriptions
- **Key artefacts it helps create:** Wireframes, UI mockups

### Canva AI
- **Pricing:** Free / Pro $15/mo
- **Best PM use cases:** Marketing visuals, presentation graphics, social media assets, quick diagrams
- **Key artefacts it helps create:** Marketing materials, presentation decks, visual assets

### Midjourney
- **Pricing:** Basic $10/mo / Standard $30/mo
- **Best PM use cases:** Concept art, brand mood boards, visual inspiration for design briefs
- **Key artefacts it helps create:** Visual references, brand direction materials

### Adobe Firefly
- **Pricing:** Free (limited) / included in Creative Cloud plans
- **Best PM use cases:** Image generation and editing within Adobe ecosystem, generative fill for design work
- **Key artefacts it helps create:** Visual assets, edited product screenshots

### Galileo AI
- **Pricing:** Waitlist / Beta
- **Best PM use cases:** AI-generated high-fidelity UI designs from text prompts
- **Key artefacts it helps create:** UI designs, component concepts
