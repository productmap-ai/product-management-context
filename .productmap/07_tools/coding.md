## Tools

### Cursor
- **Pricing:** Free / Pro $20/mo / Business $40/user/mo
- **Best PM use cases:** AI-native code editor for rapid prototyping, codebase exploration, understanding technical debt
- **Key artefacts it helps create:** Proof-of-concept prototypes, technical documentation, code reviews

### GitHub Copilot
- **Pricing:** Individual $10/mo / Business $19/user/mo
- **Best PM use cases:** AI code completion and explanation, PR review assistance, documentation generation
- **Key artefacts it helps create:** Code, tests, documentation, API specs

### v0.dev (Vercel)
- **Pricing:** Free (limited) / Premium from $20/mo
- **Best PM use cases:** React UI component generation from text prompts, rapid front-end prototyping
- **Key artefacts it helps create:** UI components, landing pages, interactive prototypes

### Bolt.new (StackBlitz)
- **Pricing:** Free (limited) / Pro $20/mo
- **Best PM use cases:** Full-stack app generation from prompts, instant browser-based development environments
- **Key artefacts it helps create:** Working web app prototypes, demo environments

### Lovable
- **Pricing:** Starter $20/mo / Launch $50/mo
- **Best PM use cases:** AI-generated full-stack web applications, rapid product concept validation
- **Key artefacts it helps create:** Working product prototypes, MVPs

### Replit
- **Pricing:** Free / Core $15/mo / Teams $40/mo
- **Best PM use cases:** Collaborative online coding, AI-assisted development, quick script writing for PM tasks
- **Key artefacts it helps create:** Data processing scripts, prototypes, automation tools

### Bubble
- **Pricing:** Free / Starter $29/mo / Growth $119/mo
- **Best PM use cases:** No-code web app development, rapid MVP building without engineering resources
- **Key artefacts it helps create:** No-code MVPs, internal tools, product prototypes
