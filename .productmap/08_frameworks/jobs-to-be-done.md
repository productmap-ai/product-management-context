# Jobs to be done (JTBD)

**Framework:** Discovery / Strategy

## Summary

Focus on the “job” the user is trying to get done in a situation, rather than demographics or features. Outcomes improve when we solve the right job.

## Key concepts

- **Job statement** — “When _____, I want to _____, so that _____.”
- Functional, emotional, and social dimensions of the job
- Competing solutions and forces (push, pull, habits, anxiety)

## When to use

- Framing problems and research questions
- Evaluating feature ideas and roadmap items
- Positioning and messaging
