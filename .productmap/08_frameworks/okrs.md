# OKRs (Objectives and Key Results)

**Framework:** Strategy / Delivery

## Summary

Set **Objectives** (qualitative goals) and **Key Results** (measurable outcomes) to align teams and track progress on what matters.

## Structure

- **Objective** — inspiring, qualitative, time-bound (e.g. “Become the go-to tool for PM discovery”).
- **Key Results** — 2–5 per objective, measurable, verifiable (e.g. “NPS from PM users ≥ 40”).

## Practices

- Set at company, team, and optionally individual level
- Typically quarterly; key results should be achievable but not trivial
- Separate from performance evaluation; focus on outcomes, not activity
