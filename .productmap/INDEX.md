# .productmap — Knowledge Index

This is the ProductMap.io PM knowledge base: a structured library of frameworks, templates, and topic guides covering the full product management lifecycle.

> **For agents:** Read this index before searching the tree. Company facts → `00_company/`. Strategy, positioning, and competitors → `01_strategy/`. Discovery and research → `02_generation/`. Metrics and economics → `03_analysis/`. Delivery artefacts → `04_delivery/` + `09_templates/`. People/process → `05_people/`. Raw exports → `10_data/`. Framework how-tos → `08_frameworks/`. Tool recommendations → `07_tools/`.

---

## 00 — Company

Company-specific facts about your product and team.

- [team.md](00_company/team.md) — **Team roster and contacts.** Content: core team table (name, role, area, email, Slack), advisors, ways of working. Use when: ownership questions, escalation paths, org structure.
- [resources.md](00_company/resources.md) — **Link inventory.** Content: tables for product docs, code repos, analytics, PM tools, comms channels, marketing assets, credentials vault links. Use when: locating systems, dashboards, or shared accounts.
- [product/onepager.md](00_company/product/onepager.md) — **Product one-pager.** Content: one-liner, what it does, components, target users, value prop, scope boundaries + agent CTA. Use when: quick product summary, positioning, onboarding context.
- [product/value-proposition.md](00_company/product/value-proposition.md) — **Value proposition.** Content: jobs, pains, gains, pain relievers, gain creators, fit assessment + agent CTA. Use when: positioning, messaging, checking product–customer fit.
- [product/product-vision.md](00_company/product/product-vision.md) — **Product vision template.** Content: vision statement, world view, pillars, differentiators, evidence, boundaries + agent CTA. Use when: long-term direction, strategic pillars.
